# 敌人战斗特性资产约定

## 当前实现

- **权威配置**：在敌人资产 [`EnemyData`](../../Assets/Scripts/Data/Combat/EnemyData.cs) 的 **战斗特性（资产）** 列表 `battleTraits` 中挂载 `EnemyBattleTraitAsset` 及其子类。与 `traitIds` / `TraitDatabase` 无强制绑定；战斗内仅读取本列表。
- **创建菜单**
  - **通用**：[`EnemyBattleTraitCommonAsset`](../../Assets/Scripts/Data/Combat/Traits/EnemyBattleTraitCommonAsset.cs) → `GoHome/Enemy/EnemyTrait/Common`（独占 **`effectLines`**、**`flavorClause`**）。
  - **特殊（Specific，对齐物品 Item Effects / Specific）**：一种机制一个 **独立 C# 叶子类型**，直接继承 [`EnemyBattleTraitAsset`](../../Assets/Scripts/Data/Combat/Traits/EnemyBattleTraitAsset.cs)，无通用 Special 基类。示例：[`EnemyPoisonStackBattleTrait`](../../Assets/Scripts/Data/Combat/Traits/EnemyPoisonStackBattleTrait.cs) → `GoHome/Enemy/EnemyTrait/Special/Enemy Poison Stack`。**类名 ≠ 菜单名 ≠ `traitDisplayName`**（日志里 `[中毒1]` 来自资产上的显示名）。
- **敌人本体**：`GoHome/Enemy/EnemyData`
- **执行与日志**：各资产通过 **`EnemyBattleTraitAsset.TryExecuteAndCompose`** 实现数值与叙事；[`EnemyBattleTraitRunner`](../../Assets/Scripts/Level/Combat/EnemyTraits/EnemyBattleTraitRunner.cs) 仅构造 [`EnemyTraitExecutionContext`](../../Assets/Scripts/Data/Combat/Traits/EnemyTraitExecutionContext.cs) 并调度虚方法，在 [`BattleManager`](../../Assets/Scripts/Level/Combat/BattleManager.cs) 中两处调用：
  - **OnEnemyReceiveHit**：玩家对敌伤害结算完成后，合并进 **当次玩家攻击** `BattleAttackEvent` 的 **`DefenderPhaseLogSuffix`**。
  - **OnEnemyAttackEnd**：敌攻伤害结算且玩家 `AfterReceiveHit` 物品合并完毕后，合并进 **当次敌攻** 的 **`AfterAttackPhaseLogSuffix`**。
- **多特性**：同一列表内按 **数组顺序** 依次执行；多条特性各自产出 `【…】` 段，段间用 **`。`** 拼接。
- **门槛（可选）**：「仅当本下对敌扣血 > 0」「仅当本下对玩家扣血 > 0」；默认不勾选时 **0 伤仍触发**。
- **数值**：通用效果经 `effectLines` 改 [`CharacterRuntimeStats`](../../Assets/Scripts/Level/Combat/Model/CharacterRuntimeStats.cs)；战斗结束快照丢弃。

## 叠层中毒（EnemyPoisonStackBattleTrait）

- **勿使用** `EnemyTraitEffectKind` 共享枚举项表达中毒；使用专用叶子资产。
- **配置**：`poisonBasePerLayer`（基数 x）；**触发**须为 **`OnEnemyAttackEnd`**（敌攻结束叠层并扣血）。无独立回合边界 tick。
- **规则（单场）**：多个中毒资产共用 **一套层数**；基数取本场已出现过的 **max(x)**。每次敌攻结束且特性触发成功：**层数 +1**，玩家立刻失去 **当前层数 × 基数** HP；日志句为 [`EnemyPoisonTraitNarration.FormatPoisonRoundEndClause`](../../Assets/Scripts/Level/Combat/EnemyTraits/EnemyPoisonTraitNarration.cs)（「回合结束失去…」），经 `ComposeFullBlock` 包进 `【敌人使用[特性名]，…】`。例如 x=7：第 1 次触发 7（1 层），第 2 次 14（2 层），第 3 次 21（3 层）。
- **运行时入口**：[`BattleManager.TryApplyEnemyPoisonStackFromTrait`](../../Assets/Scripts/Level/Combat/BattleManager.cs)。

### 迁移说明

旧版 `EnemyPoisonTraitTemplateAsset` / `EnemyBattleTraitSpecialAsset` 已移除；中毒请改用 **`EnemyPoisonStackBattleTrait`** 资产。旧 YAML 中 `effectLines`/`flavorClause` 若挂在旧中毒类型上已不适用（Special 无此字段）。

## 日志格式

单条特性：`【{敌人名}使用[{特性名}]，{正文}。】`

- **Common**：正文 = 通用效果句 + `flavorClause`（最后）。
- **Special 叶子**：正文由该类型代码拼装（如中毒仅机制句，无风味字段）。

纯文案、无数值（Common）：效果行 `Kind` 为 `None` 且填写 **自定义文案**。

## 验收建议

1. **受击 0 伤**：未勾选「仅当对敌扣血」时，`OnEnemyReceiveHit` 特性仍执行。
2. **敌攻后顺序**：同一条敌攻日志中，先 `AfterReceiveHit` defender 段，再 `OnEnemyAttackEnd` 的 AfterAttack 段。
3. **修饰**：Common 配置的攻防/暴率等在后续结算中生效。
4. **中毒**：`OnEnemyAttackEnd` + `EnemyPoisonStackBattleTrait` 时，每次敌攻结束层数递增并扣血，日志含正确「回合结束失去…」与层数。

## 规划/可选改造

- **Editor 校验**：`EnemyTraitEffectKind` 与叙事模板表枚举全覆盖。
- **吸血类特性**：可新增独立叶子类型（如 `EnemyLeechOnHitBattleTrait`），override `TryExecuteAndCompose`，勿做 Template 通用类。
