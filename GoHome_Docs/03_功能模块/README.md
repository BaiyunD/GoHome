# 03_功能模块

## 本章用途

本章从“**怎么改功能**”的视角组织文档：每页尽量回答三件事：

- **从哪里进**：修改入口与调用链（哪个按钮/哪个 Manager）
- **改哪里**：最小改动的关键文件/关键方法
- **怎么验**：必须验证的 UI/数据/严格校验点
