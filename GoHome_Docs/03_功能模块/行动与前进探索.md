# 行动与前进探索（Action -> AdvanceFlow）

本页覆盖“玩家点击按钮后，如何进入前进/探索流程”的修改入口与验证要点。

## 入口链路

1. UI 按钮入口
   - `Assets/Scripts/UIs/ActionBarPanel.cs`
   - 前进：`OnAdvance()`
   - 探索：`OnExplore()`
2. 行动入口 API
   - `Assets/Scripts/Manager/ActionManager.cs`
   - `TryAdvance()` / `TryExplore()`
3. 统一流程控制
   - `Assets/Scripts/Level/Flow/AdvanceFlowController.cs`
   - `RunFlowCoroutine(isAdvance)`

## UI 命名更新（本轮）

- 行动按钮组件统一命名为 `ActionBarPanel`。
- 行动流程相关文档与代码引用统一使用 `ActionBar`/`ActionBarPanel` 语义。
- 本页仅涉及入口命名；前进/探索路由行为与概率逻辑保持不变。

## 验证要点

- `ActionBarPanel` 的前进/探索按钮调用仍落到 `ActionManager.TryAdvance/TryExplore`。
- 流程中断后按钮可恢复可点击（状态回到 `Idle`）。
- UI 路由规则不变：流程面板开启时不破坏常驻状态栏展示。

## 物资追加奖励（收口后）

- 主奖励先由 `RegionLootService.RollAndGrant` 结算。
- 追加奖励统一由 `ItemEffectDispatcher.ApplyAdvanceSupplyForInventory` 遍历库存触发。
- `210/214` 文案顺序固定为：`放大镜` 片段优先、`晓月手链` 片段其次（与历史展示一致）。
- 触发来源可在日志中看到 `source=Asset/Builtin`，用于判断是否走回退链路。
