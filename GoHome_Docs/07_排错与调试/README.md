# 07_排错与调试

## 本章边界

本章以“**代码排错**”为主，Unity/Editor 只点到必要位置。目标是：遇到异常时能快速回答：

- **根因在哪**（数据、配置、订阅、初始化顺序、状态机）
- **从哪里插日志/断点**（入口方法与关键变量）
- **怎么最小复现**（缩小到 1 条调用链）

> 常见报错对照（偏症状）也可看：[`../08_常见问题/README.md`](../08_常见问题/README.md)

> UI 命名口径：Page/Panel/Modal 语义化命名已生效；其中 `EventNarrationModal` 与 `ResultToastModal` 为轻覆盖层（非 `PanelType`），且打开 Page 时仍会路由隐藏 narration。
