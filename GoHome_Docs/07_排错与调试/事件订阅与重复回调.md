# 事件订阅与重复回调：OnEnable/OnDisable 排查法

本页处理两类常见问题：

- **重复回调**：一次动作触发多次 UI 刷新/多次扣资源
- **销毁后回调**：对象已销毁/失活但还收到事件，导致 NRE

## 概念与边界

- Unity 对象的生命周期：`Awake` → `OnEnable` → `Start` →（运行）→ `OnDisable` → `OnDestroy`
- 事件订阅建议成对出现：
  - 订阅：`OnEnable`
  - 解绑：`OnDisable`

## 本项目约定（推荐）

### 1) 不在多个地方重复订阅同一事件

同一个面板/组件，只在一个生命周期点订阅一次，不要同时在：
- `Awake` 订阅 + `OnEnable` 再订阅
- `Start` 订阅 + 重新打开面板时再订阅

### 2) 解绑必须可靠

只要 `OnEnable` 订阅了，就必须在 `OnDisable` 解绑。

## 常见错误与症状

- 打开/关闭面板几次后，刷新次数越来越多（重复订阅）
- 场景切换后偶现 NRE（旧对象还在收到事件）

## 如何修改（排查步骤）

1. 先观察症状是否“次数递增”
   - 如果是：十有八九重复订阅
2. 在订阅点加临时日志（包含 `GetInstanceID()`）
   - 用来确认“同一对象订阅多次”还是“多个对象各订阅一次”
3. 检查 `OnDisable/OnDestroy` 是否确实会执行
   - 某些对象被 `DontDestroyOnLoad` 保留，生命周期不同
4. 合并订阅点并补齐解绑
   - 订阅/解绑写成对，避免分散

## 验证清单

- 重复打开面板/切换场景后，回调次数不递增
- 对象失活/销毁后不再收到事件
- 关键 UI 刷新只触发一次（除非明确需要多次）
