# GoHome Docs（项目知识库）

## 简介

这里是 GoHome 的分层项目知识库（类似技术文档网站）。阅读方式建议：

1. 先从本页目录选择主题
2. 再进入子目录阅读具体细节
3. 若文档未覆盖当前问题，请先在聊天里向你确认，再补文档/实现

> 说明：本知识库用于“项目介绍 + 如何修改”的长期指南；当日实现过程记录写入 `DEVLOG.md`。

## 阅读口径（重要）

- 文档默认采用“双段结构”：`当前实现` + `规划/可选改造`
- 进行实现与排错时，请以“当前实现”为准；“规划/可选改造”仅作为后续演进参考
- 若你发现文档与代码不一致，优先回到聊天确认后再改文档

## UI 命名基线（2026-04-23）

- `PanelType` 当前采用 `HudStatus`、`ActionBar`、`InventoryPage`、`CraftPage`、`TraitsPage`、`RestPage`、`EndPage` 命名。
- `RandomEvent` / `Battle` / `CombatStats` 仍归类为 Panel。
- `EventNarrationModal` 与 `ResultToastModal` 属于 Modal 轻覆盖层（非 `PanelType`）。
- 当前行为保持不变：打开 Page 时，路由仍会主动隐藏事件叙述。
