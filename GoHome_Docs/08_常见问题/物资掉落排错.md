# 物资掉落排错

本页用于定位“前进/探索命中物资分支后，结果不符合预期”的问题。

> 先看功能链路：[`../03_功能模块/行动与前进探索.md`](../03_功能模块/行动与前进探索.md)  
> 再看配置规范：[`../06_配置与数据/RegionLootTable配置与命名规范.md`](../06_配置与数据/RegionLootTable配置与命名规范.md)

## 快速定位顺序（建议）

1. 先确认 `AdvanceFlowController` 已挂 `regionLootTable`
2. 再确认当前 `regionCode` 在表里存在且格式正确（`main_sub`）
3. 再检查地区条目是否“有效可抽取”（权重>0，ID/金额合法）
4. 最后验证晓月手链条件（仅空结果时触发，且最多一次）

## 常见问题与处理

### 1) 命中物资分支但什么都没加

可能原因：
- `regionLootTable` 未挂载
- 当前地区未配置对应 `regionCode`
- 该地区条目全无效（`weight<=0`、`itemId<=0`、`moneyAmount<=0`）

处理建议：
- 在 `AdvanceFlowController` Inspector 检查 `regionLootTable`
- 在 `RegionLootTable` 中核对当前地区编码（如 `1_2`）
- 至少保留一个有效条目并确保权重大于 0

### 2) 经常“什么都没发现”

可能原因：
- `noLootProbability` 过高
- 实际可抽取条目太少，且权重分配不合理

处理建议：
- 先保持默认档位 `20/50/20/10`
- 再按体验逐步微调，不要一次改太大

### 3) 掉落数量不对（不是 1 或 2）

可能原因：
- 条目配置与预期不一致（`countOption` 误设）
- 误把“掉落种数”与“单条目数量”混淆

处理建议：
- 逐条核对 `countOption`：`One` 或 `Two`
- 记住：`0/1/2/3` 是“种类数”，不是“每种数量”

### 4) 金钱没有增加

可能原因：
- 条目类型不是 `Money`
- `moneyAmount <= 0`
- 条目权重为 0，实际抽不到

处理建议：
- `rewardType` 设为 `Money`
- `moneyAmount` 设为正数
- 给金钱条目合理权重

### 5) 晓月手链没有触发二次掉落

可能原因：
- 这次结果并非“空结果”（非空不会触发）
- `xiaoYueBraceletItemId` 配错
- 背包中该物品数量为 0（当前实现把数量作为等级）
- `retryChancePerLevel` 偏低导致概率未命中

处理建议：
- 先复现“空结果”场景再观察
- 核对手链物品 ID
- 确认背包中有手链数量
- 调高 `retryChancePerLevel` 做验证（验证后再调回）

### 6) 触发后流程卡住或按钮不可点

可能原因：
- 流程中断后状态未回到 `Idle`（通常伴随报错）
- 其他模块异常打断了正常回收

处理建议：
- 优先看 Console 报错上下文
- 重点检查“地区池缺失/条目非法”等严格中断日志
- 复测时先用最小配置（1个地区+2个有效条目）

## 最小自测清单（5分钟）

- 前进/探索都能触发物资分支
- 物品与金钱都能被发放
- 单次结果只会是 0~3 种
- 单条目数量只会是 1 或 2
- 空结果时，晓月手链最多重试一次
- 异常配置时会明确报错并恢复到可继续点击状态
