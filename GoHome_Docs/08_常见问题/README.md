# 08_常见问题

## 本章边界

本章是“排错导航”，目标是让你在 1–3 分钟内定位到问题归因与下一步动作：

- 编译失败：缺文件/类型冲突/引用丢失
- 运行时空引用：Inspector 未绑定/单例未初始化/资源加载为空
- 严格校验报错：`regionCode/enemyId` 等配置缺失导致的 hard fail
- 战斗/事件联动异常：遇敌开战失败、UI 不刷新等
- 物资掉落配置异常：地区池缺失、条目非法、手链未触发等

> 想从业务角度定位入口，请先看：[`../03_功能模块/README.md`](../03_功能模块/README.md)
