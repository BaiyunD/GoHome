# 道具效果分发顺序与冲突规则

本页定义 `ItemEffectDispatcher` 在多效果场景下的统一执行顺序、冲突裁定与去重规则。

## 1. 统一执行顺序

在同一 Hook 内按以下顺序执行：

1. `priority`（小值优先）
2. `effectId`（字典序）
3. `itemId`（升序，保证稳定）

> 说明：稳定排序是回归可复现的前提。

## 2. Hook 分组建议

- `Passive`
- `AdvanceSupply`
- `Rest`
- `Use`
- `Battle`（细分：`BeforeAttack`/`AfterAttack`/`BeforeReceiveHit`/`AfterReceiveHit`/`TryFlee`）

每次只在当前 Hook 执行对应效果，禁止跨 Hook 直接互调。

## 3. 冲突裁定

- 同层同类型效果：按排序顺序逐个叠加。
- 百分比与固定值冲突：先百分比，再固定值。
- 最终结果统一钳制：
  - 伤害、恢复、概率等数值不得越界。
- 受击反弹类效果基于“实际受伤值”，不得基于理论值。

## 4. 去重与限次

- 单次流程内同 `effectId` 默认只触发一次（可在效果资产上显式允许多次）。
- 概率触发效果建议记录本次 roll（用于日志排错）。
- 需要“当日一次”的效果必须由上下文提供去重状态。

## 5. 文案职责边界

- 效果资产：返回结果数据（如掉落、恢复、状态变更）。
- 分发器：聚合结果，保持顺序。
- 流程层：统一拼接 UI 文案与输出日志。

## 6. 回归重点

- 多效果组合下顺序稳定。
- 同输入条件下多次运行结果一致（概率除外，但触发顺序一致）。
- 新增效果不改变既有效果执行顺序。
