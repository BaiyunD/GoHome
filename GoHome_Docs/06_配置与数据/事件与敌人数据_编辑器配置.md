# 事件与敌人数据（编辑器配置）

本页面向“在 Unity 里怎么配”的工作流：资源放哪、Inspector 填什么、缺配置会触发哪些严格失败。

## 概念与边界

- 事件数据：通常由 `GameEvent` 资产承载（条件 + 叙述 + 选项 + 结果）
- 敌人数据：由 `EnemyData` 资产承载（ID/地区/属性模板等）
- 运行时联动：事件遇敌只产出 `enemyId`，战斗侧再按地区池解析

## 本项目约定

### 1) 事件（GameEvent）配置要点

- `EventCondition.regionCode`：
  - 必须是 `main_sub` 格式（例：`1_2`）
  - 用于 `EventManager` 按地区筛选事件
- 遇敌结果（EnemyEncounter）：
  - 必须填写 `enemyId`
  - 不要在事件里直接引用敌人资产（保持值传递）

### 2) 敌人（EnemyData）配置要点

- `enemyId`：必须稳定且唯一（在同一地区池中不能重复）
- `regionCode`：必须是 `main_sub` 格式，用于归属地区池

### 3) 敌人池（EnemyPoolService）配置要点

- 需要把所有可遇敌的 `EnemyData` 资产加入列表（否则战斗解析不到）
- 解析规则：**按 regionCode 取池** → 在池内按 `enemyId` 查找

## 常见错误与症状

- 事件 regionCode 漏填/格式错：该事件永远不会被选中，或在筛选/触发时严格失败
- 遇敌结果 enemyId 漏填：事件执行到遇敌时严格失败，无法开战
- EnemyData 的 regionCode 填错：敌人进错地区池，导致“看似配置了但找不到”
- 忘了把 EnemyData 加到 EnemyPoolService：`enemyId` 存在但池里没有 → 开战严格失败

## 如何修改（编辑器步骤）

1. 新增/修改事件
   - 打开事件资产，确认 `regionCode` 正确
   - 若结果为遇敌，填写 `enemyId`
2. 新增/修改敌人
   - 打开敌人资产，确认 `enemyId/regionCode` 正确
3. 更新敌人池
   - 在场景中的 `EnemyPoolService`（或其配置对象）把新敌人加入列表

## 验证清单

- 触发随机事件时，能在当前地区命中该事件（regionCode 生效）
- 遇敌事件触发后，能成功开战（enemyId 在当前地区池可解析）
- 缺配置时，Console 能看到明确的错误（包含 `regionCode/enemyId`）
