# 项目结构

## 目标

快速理解关键目录职责，并能在需要修改时定位到正确入口文件。

## 关键目录速览

- `Assets/`
  - 运行时资源与脚本的核心目录（场景、Prefab、ScriptableObject、Sprites、Scripts 等）。
- `Assets/Scripts/`
  - 主要 C# 脚本目录（管理器、系统逻辑、UI 脚本等）。
- `Assets/Resources/`
  - 通过 `Resources.Load` 加载的资源（若项目使用该模式）。
- `Packages/`
  - Unity Package 配置与依赖声明。
- `ProjectSettings/`
  - Unity 项目设置。
- `Docs/`
  - 项目过程记录与零散文档（当前包含 `DEVLOG.md` 等）。
- `GoHome_Docs/`
  - **分层项目知识库根目录**（面向“项目介绍 + 如何修改”的长期指南）。

## 文档入口

- 知识库首页：`GoHome_Docs/README.md`
- 当日开发记录：`DEVLOG.md`

## 修改定位建议

- **改业务逻辑**：优先按生命周期定位：`Assets/Scripts/Level/`（关卡流程）与 `Assets/Scripts/Session/`（会话状态）。
- **改 UI**：优先从 `Assets/Scripts/UI/`（`UI/Core`、`UI/Menu`、`UI/InGame`）入口确认面板开关策略。
- **改配置/资源字段**：先查对应 ScriptableObject/配置文件，再查消费它的管理器。

## TODO：挂载Inspector（迁移后必查）

> 本项目近期做过脚本目录迁移（保留 `.meta` GUID 以避免丢引用）。若 Unity 仍出现 `Missing (Mono Script)` 或按钮不可点，按本清单排查。

### 1) 场景必备对象

- `MainMenuScene`
  - 必须存在可用 `EventSystem`（若场景漏配，`MainMenuController` 会运行时兜底创建）。
- `GameScene`
  - 必须存在项目内约定的 Manager 聚合对象（你当前习惯为 `Manager`），并挂载关卡级脚本（Level 层）：`GameManager`、`ActionManager`、`AdvanceFlowController`、`BattleManager`、`EventManager`、`EnemyPoolService`、`RestManager`、`EndingManager` 等。

### 2) Inspector 引用必查（常见 Missing 来源）

- `UIManager`：大量 `[SerializeField]` 引用 UI 面板（HUD/各 Page/Modal），任何一个丢失都会导致 UI 不刷新或无法打开页面。
- `HudStatusPanel`：需要绑定 `PlayerDatePanel` 与 `RouteInfoPanel`（否则 HUD 不刷新）。
- `InGameSettingsController`：需要绑定 `settingsPanelRoot/saveFailedDialogRoot/...` 等 UI 节点（否则返回主菜单/保存提示异常）。

### 3) 快速判定是否需要重新挂载脚本

- 若组件头部显示 `Missing (Mono Script)`：说明 GUID/脚本资产未正确匹配，需手动重新挂载对应脚本（先让 Unity 完成一次 reimport，再判断）。
- 若按钮完全无 Hover：优先检查 `EventSystem` 是否存在且启用。
