# 代码审查清单

## 目标

提交或交付前快速自检，减少“看起来能跑但隐藏问题很多”的情况。

## 变更范围

- [ ] 只修改了需求涉及的代码块（无无关改动）
- [ ] 没有做“顺手重构/顺手整理”
- [ ] 没有修改 `.meta` 文件

## 命名与风格

- [ ] 命名符合约定（类/方法 PascalCase；私有字段 `_camelCase`；常量 UPPER_SNAKE_CASE）
- [ ] 新增可配置字段使用 `[SerializeField] private`，没有用 `public` 暴露字段
- [ ] 大括号 Allman，缩进 4 空格

## 运行时风险

- [ ] 单例组件不会重复挂载（否则 Instance 覆盖/Destroy 逻辑可能异常）
- [ ] 协程宿主生命周期正确（UI 面板隐藏不会中断关键协程）
- [ ] 缺失 Inspector 绑定会有明确错误日志

## 验证

- [ ] 对修改文件跑过 `ReadLints`（至少保证无新增静态错误）
- [ ] 关键路径做过最小回归（例如：按钮->面板->流程闭环）
- [ ] 若编译/运行失败：已明确是否为“本次引入”还是“既有问题”\n+
## 交付回报（给 AI / 给人）\n+\n+- [ ] 修改文件清单\n+- [ ] 每个文件关键改动\n+- [ ] 验证结果（含 ReadLints）\n+- [ ] Inspector 待补配置项\n*** End Patch
