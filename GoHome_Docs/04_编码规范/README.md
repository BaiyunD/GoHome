# 编码规范

## 概述

本目录用于沉淀 GoHome 项目的编码规范与代码审查要点，目标是：

- 降低改动时的“风格分裂”与返工
- 用最小改动策略减少 Unity 项目改动风险
- 让 AI 与人都能快速按规范执行修改

## 导航

- [C#命名规范](./C#命名规范.md)：类/方法/字段/属性/局部变量/常量命名约定
- [Unity约定](./Unity约定.md)：组件获取、协程命名、常见禁用写法等
- [代码格式与最小改动原则](./代码格式与最小改动原则.md)：Allman、缩进、using 处理、不要动 .meta 等
- [代码审查清单](./代码审查清单.md)：提交前必查项（含 Inspector 待配、ReadLints 等）
- [Manager目录冻结与命名落位规则](./Manager目录冻结与命名落位规则.md)：严格后缀命名、生命周期落位与软硬门禁
