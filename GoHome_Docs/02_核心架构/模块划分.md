# 模块划分

本页是“模块划分”的**导航页**。规划阶段默认只读本页；只有命中某个模块时，才进入该模块的细节页。

> 说明：此文档基于当前代码结构总结；若后续结构调整，请同步更新。

## 模块索引

### 生存/结局（Game）
- 作用：玩家运行时信息与游戏结束判定入口。
- 关键入口：`GameManager.NewGame()` / `GameManager.GameOver()`。
- 细节：[`模块划分/Game.md`](./模块划分/Game.md)

### 路线进度（Route）
- 作用：day/distance/region 权威进度源与事件广播。
- 关键入口：`RouteProgressManager.Initialize/Advance/Rest`。
- 细节：[`模块划分/Route.md`](./模块划分/Route.md)

### 行动入口（Action）
- 作用：对外暴露前进/探索/休息入口，转交流程控制器。
- 关键入口：`ActionManager.TryAdvance/TryExplore/TryRest`。
- 细节：[`模块划分/Action.md`](./模块划分/Action.md)

### 前进/探索流程（AdvanceFlow）
- 作用：行动状态机（Idle/Running/Transit）+ 扣除消耗 + 概率分流（物资/事件/战斗）。
- 关键入口：`AdvanceFlowController.TryAdvance/TryExplore`。
- 细节：[`模块划分/AdvanceFlow.md`](./模块划分/AdvanceFlow.md)

### 事件系统（Event）
- 作用：随机事件筛选与执行，事件中转遇敌以 `enemyId` 传值。
- 关键入口：`EventManager.GetRandomEventByRegionCode` / `EventManager.RandomEventIE`。
- 细节：[`模块划分/Event.md`](./模块划分/Event.md)

### 战斗系统（Battle）
- 作用：战斗生命周期与 UI 开关，支持按 `enemyId` 定位敌人后开战。
- 关键入口：`BattleManager.StartBattleByEnemyId`。
- 细节：[`模块划分/Battle.md`](./模块划分/Battle.md)

### 背包/物品（Inventory/Items）
- 作用：库存 dict + 变更事件，UI 展示与使用交互。
- 关键入口：`InventoryManager.AddItem/RemoveItem`。
- 细节：[`模块划分/Inventory.md`](./模块划分/Inventory.md)

### UI 管理（UI）
- 作用：面板开关策略（当前为 Page/Panel 分层，Modal 预留）与统一刷新入口。
- 关键入口：`UIManager.OpenUIEntry/CloseUIEntry/UpdateInfo`。
- 细节：[`模块划分/UI.md`](./模块划分/UI.md)

### 特性系统（Traits）
- 作用：特性定义注册/持有者管理/清空，与战斗/玩家触发扩展相关。
- 关键入口：`TraitManager` 的添加/清理逻辑。
- 细节：[`模块划分/Traits.md`](./模块划分/Traits.md)
