# 核心架构

## 概述

本目录用于描述 GoHome 项目的核心架构（基于现有代码真实结构），帮助你在修改前先确认：

- 谁是**权威数据源**（例如距离/天数/地区进度）
- 谁负责**流程调度**（例如前进/探索分流）
- 谁负责**UI 面板开关与信息刷新**

阅读建议：
- 先看各文档里的“当前实现”段落，避免把规划项当作现状
- 与 UI 相关的描述，以 `OpenUIEntry/CloseUIEntry + UIRouter + UIStateMachine` 为准
